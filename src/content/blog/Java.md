# ☕ Java desde cero

Java es uno de los lenguajes de programación más utilizados del mundo.

En esta serie voy a aprender Java desde cero, paso a paso, empezando por los conceptos más básicos y avanzando hacia programación orientada a objetos, aplicaciones, APIs y proyectos reales.

## ¿Qué es Java?

Java es un lenguaje de programación orientado a objetos diseñado para crear aplicaciones que puedan ejecutarse en diferentes sistemas operativos.

Una de sus ideas principales es:

> Write once, run anywhere.

Es decir, escribir el programa una vez y poder ejecutarlo en distintos sistemas gracias a la Máquina Virtual de Java, conocida como JVM.
